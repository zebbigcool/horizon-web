Servers

Pick a server and join it. The game starts and connects for you.

    Horizon servers are added as host:port (they take WebSockets beside Minecraft's port). Eaglercraft servers are added as a wss:// address. Servers you add are kept in this browser; joining uses your player name from the game's Edit Profile screen.

      Game

      Classic is the client with shared worlds, public rooms, packs and mods from this launcher, and server joining. New is a newer one-page client with touch controls, a WebGL option and its own settings; it opens on its own menus, so Memory, Packs, Servers and Show-my-worlds here don't apply to it.

      When on, a world you share (with a join code) is listed under Public worlds on the Play page, with your player name, until you close it.

      Prints what the game reports on the screen. Useful on a device without developer tools, if the game stays black.

      The launcher goes full screen on your first tap or key press. Esc leaves it, and it stays out until you reload.

      Relays

      A relay hands out join codes for shared worlds and introduces players to each other. This site's own relay is built in; add the address of another (wss://host) and it is tried first. Takes effect the next time the game starts.

        z's horizon

        A launcher for Horizon, Minecraft Java 26.3 rewritten in Rust and run in the browser with WebGPU. Shared worlds connect through this site's own relay, so a join code works from any device.

        Launcher data

        Settings and relays are kept in this browser. Clearing them does not delete your worlds.
