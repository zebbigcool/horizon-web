Servers

Pick a server and join it. The game starts and connects for you.

    Horizon servers are added as host:port (they take WebSockets beside Minecraft's port). Eaglercraft servers are added as a wss:// address. Servers you add are kept in this browser; joining uses your player name from the Profile page.

    Ordinary Java servers don't take WebSockets, so they are reached through a Wisp server, which opens the real connection for you. Add the Wisp server's address above, then tick "Java server" when adding one. The Wisp server sees which servers you join, so use one you trust or run yourself. Servers that check your Microsoft account (online mode) refuse the join for now; servers that allow offline-mode names work.

      Account

      Sign up to keep your launcher settings, profile and worlds in the cloud and use them on any device.

      A username is 3 to 16 letters, numbers or underscores; a password is at least 8 characters. Your password is never kept as text. There is no password reset, so remember it.

      This is your Minecraft name in the game and on lists. Anyone can use the same display name, so don't rely on it to tell people apart: 1 to 16 characters, no spaces.

      Your username is yours alone: nobody else can have it, and it never changes. Staff and bans go by it, so a copied display name gets nothing.

              Instances

              Each instance has its own worlds, options, packs and player profile (name, skin and cape). The active one is what the game starts with.

                Instances are kept in this browser. Deleting one removes its worlds for good.

                Profile

                Your name, skin and cape for this instance. They apply the next time the game starts, so set them before you join a shared world or server.

                You're signed in, so your name in the game is your account's username. You can still change the skin and cape.

                This browser can't keep files for the game, so the profile can't be saved here. Set it in the game's own menu instead.

                1 to 16 characters, no spaces. Leave empty to keep the name the game made for you.

                Pick a character, or upload your own skin (a 64×64 or 64×32 PNG).

                Upload a cape (a 64×32 or 22×17 PNG) to wear it.

                Settings

                How the game starts. These are kept in this browser.

                Game

                Classic is the client with shared worlds, public rooms, packs and mods from this launcher, and server joining. New is a newer one-page client with touch controls, a WebGL option and its own settings; it opens on its own menus, so Memory, Packs, Servers and Show-my-worlds here don't apply to it.

                When on, a world you share (with a join code) is listed under Public worlds on the Play page, with your player name, until you close it.

                For Chromebooks and other computers with little memory (4 GB or less). The game uses two threads at most, frees the page's copy of its files as soon as it can, and the first time it starts it sets short view distances, no clouds, minimal particles and no mipmaps or biome blending (change them in the game's Video Settings afterwards and they stay). Turn it off on a stronger computer. Takes effect the next time the game starts.

                Looks around with the mouse's own movement, without the system's acceleration or smoothing. Try it if the camera flicks while you move it. It can feel a little different (faster or slower) than before; if the browser can't do it, the game falls back by itself. Takes effect the next time the game starts.

                Ignores a single mouse movement too big to be real. Strict also ignores some fast flicks of your own, so use it only if Normal doesn't stop the camera jumping.

                Prints what the game reports on the screen. Useful on a device without developer tools, if the game stays black.

                The launcher goes full screen on your first tap or key press. Esc leaves it, and it stays out until you reload.

                Relays

                A relay hands out join codes for shared worlds and introduces players to each other. This site's own relay is built in; add the address of another (wss://host) and it is tried first. Takes effect the next time the game starts.
